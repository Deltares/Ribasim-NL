# Ribasim-NL

**Documentation: https://ribasim.nl/**

Ribasim-NL builds the Dutch national water model with [Ribasim](https://ribasim.org/), a water resources model.
A reproducible [DVC](https://dvc.org/) pipeline turns source data and the Python code in this repository into a nationwide schematization, from the models of Rijkswaterstaat and 21 water authorities.

- [Model derivation](https://ribasim.nl/workflow/)
- [Model viewer](https://ribasim.nl/viewer.html)
- [Contributing](https://ribasim.nl/dev/)

Earlier work by Sweco ([ribasim_lumping](https://github.com/harm-nomden-sweco/ribasim_lumping)), HKV ([TKI-ribasim](https://github.com/rbruijnshkv/TKI-ribasim)) and D2Hydro ([lhm-ribasim](https://github.com/d2hydro/lhm-ribasim)) came together here.
Where needed, developments are coordinated with the generic functionality in [Deltares/Ribasim](https://github.com/Deltares/Ribasim).
