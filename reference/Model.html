add_basin_area

Model.add_basin_area(
    geometry,
    node_id=None,
    meta_streefpeil=None,
    tolerance=0.001,
)

Add geometry to the basin area of Basin node_id, taking it from the other basin areas.

Without node_id, it is added to the one Basin within geometry. The polygons on average narrower than tolerance are slivers, which are not added, see select_basin_area.

Parameters

to_node_id : int | list node_id or list of node_ids to connect control node to data: data for the control node

offset_node_id : int | None, optional User can explicitly specify a offset_node_id for a left-offset of the control-node. by default None node_geom : tuple | None, optional User can explicitly specify an Point for the control node. If None, see node_offset. by default None node_offset : int, optional left-side offset of control node to to_node_id in case it’s one node_id and node_geom is not defined, In other cases this value is ignored. add_link

Model.add_link(from_node, to_node, link_type='flow', name='', **kwargs)

Alternative method to add links to the model.

model.link.add() sometimes raises AttributeError: Flagsobject has no attribute _allows_duplicate_labels when calling _concat(). It seems that the gpd.GeoDataFrame to add to the existing link-table, using a pydantic scheme, causes this exception. Untill this can be solved we bypass by concating a non-pydantic-schemed GeoDataFrame to the link-table.

Args: from_node (int): Node to connect from to_node (int): Node to connect to link_type (str, optional): link-type. Defaults to “flow”. name (str, optional): link name. Defaults to ““. kwargs: additional attributes that will be passed as meta-values to the row in the dataframe

Add straight links between pairs of (from_node, to_node), like add_link.

Apply model edits stored in a GeoPackage, with a layer per edit method (action).

Every row of the layer is a call of the method with the columns that are arguments of the method.

Args: edits_gpkg: GeoPackage with a layer per action, e.g. “merge_basins” or “remove_node” actions: names of the methods to apply, in this order sort_by_order: apply the rows in the order of an “order” column, if the layer has one drop_na: don’t pass missing values, so the method’s defaults are used

fill_basin_area_holes

Model.fill_basin_area_holes(areas_gpkg, excluded=None)

Give the parts of the areas of areas_gpkg that no basin area covers to a Basin, one basin area per Basin.

The uncovered part of an area goes to the Basin that covers most of that area, and an area that none covers to the Basin it shares the longest border with, preferably in the same drainage area, as in the lumping, see ribasim_nl.lumping.network.fill_holes. What lies within excluded is not part of the model: it is removed from the basin areas, and not filled. Raises if a basin area belongs to no Basin, or a Basin has no basin area.

select_basin_area

Model.select_basin_area(geometry, tolerance=0.001)

Select the basin areas that equal geometry, or else each of its polygons.

Geometries are taken as equal if their boundaries are on average at most tolerance m apart. That allows for the differences between the results of versions of GEOS, which can also merge or separate adjacent parts of an area. So without a basin area that equals a polygon, the basin areas that together make it up are selected, or else the polygon is split from the basin areas that cover it, as basin areas of the same nodes. Polygons on average narrower than tolerance are slivers, which differ between versions of GEOS, and are not selected.

split_basin

Model.split_basin(
    line=None,
    basin_id=None,
    geometry=None,
    assign_unique_node=True,
)

Split the basin area that geometry crosses in two parts along it.

The basin area is the one of basin_id that the line crosses, or else the one that contains its middle. The parts keep its node, or with assign_unique_node, go to the one Basin within them that has no basin area.
