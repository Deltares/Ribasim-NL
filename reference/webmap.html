attribute_tables

webmap.attribute_tables(database)

List the non-spatial Ribasim tables in a GeoPackage.

color_domain

webmap.color_domain(values, scale)

Robust color scale domain: 2nd to 98th percentile, of magnitudes for log and diverging scales.

concentration_variable

webmap.concentration_variable(substance, values, units)

The color scale of a substance, linear from zero.

Up to the highest value, since a substance that reaches few Basins would be saturated by a percentile, and a fraction of the water then goes up to about 1, like the others. The residence time has no such limit: the few stagnant Basins would make all others look the same.

downcast_int64

webmap.downcast_int64(table)

Cast int64 columns that fit to int32, since JavaScript readers return int64 as BigInt.

export_basin_area

webmap.export_basin_area(database, nodes, path)

Export Basin / area polygons as vector tiles; attributes are looked up by node_id.

The areas of the storing (‘bergend’) Basins overlap those of the flowing Basins they belong to. The tiles keep this order and the viewer draws and picks the last feature on top, so the storing Basins come first, to show and select the flowing Basins by default.

export_concentration

webmap.export_concentration(source, ids, times, by_id, by_time)

Export the Basin concentrations per Basin for charts and per time step for the map, with a column per substance.

The viewer reads only the column of the chosen substance, so a long list of substances does not slow it down. The Basins and time steps must be those of the Basin results, so the viewer can reuse their order on the map.

export_observations

webmap.export_observations(database, results_dir, times, output_dir)

Export how well the results fit the measurements of the Observation nodes, see ribasim_nl.goodness_of_fit.

The fit of each observed variable over the whole run is written as a table, and the difference simulated - observed at each of the times for the map, which is NaN where either value is missing. Returns None if no Observation node is compared.

export_results

webmap.export_results(results_dir, output_dir)

Export Basin and flow results and Basin concentrations, both per feature for charts and per time step for the map.

export_waterboards

webmap.export_waterboards(source, path)

Export simplified water board boundaries as GeoJSON.

export_webmap

webmap.export_webmap(toml_path, waterboards_path, output_dir)

Export a Ribasim model to a directory of web-friendly files plus a manifest.json.

The water boards are left out if waterboards_path is None. The viewer fetches files as <path>?v=<hash> so they can be cached indefinitely.

write_by_id

webmap.write_by_id(ids, times, data, id_dim, path)

Write long-format Parquet sorted by id, one row group per block of ids, for per-feature time series.

The viewer finds the row group of an id by the statistics of the id column. Those of the other columns are left out, since they would be read with the file metadata of each feature, and grow with the number of columns.

write_by_time

webmap.write_by_time(ids, data, id_dim, path)

Write Parquet ordered by time then id, one row group per block of time steps, for map animation.

write_parquet

webmap.write_parquet(df, path, row_group_size=ROW_GROUP_SIZE)

Write a DataFrame to Parquet, see write_table.

write_table

webmap.write_table(table, path, row_group_size=ROW_GROUP_SIZE)

Write zstd compressed Parquet with column statistics for row group lookup.

The float32 coordinates are stored with byte stream split, which compresses the link coordinates about 40% better than the plain encoding. The float64 input tables repeat many values, which suit dictionary encoding.
