flow_paths

flow_paths

Routes of flow links through Junctions, and changes to them that only change the layout.

A Junction only merges or splits flow, so the flow links from a node through Junctions up to the next non-Junction nodes form the route of that node. Ribasim replaces each pair of links into and out of a Junction by a direct link, see simplify_graph! in the Ribasim core. Moving or adding Junctions on a route therefore changes how links are drawn, not how water flows, as long as each node keeps exchanging water with the same non-Junction nodes.

attach_to_tree

flow_paths.attach_to_tree(routes, start, points)

Attach points to the tree of routes from start, each with a straight line from the nearest point of the tree.

The points nearest to the tree are attached first, such that the others can branch off their lines. Where a line branches off a segment, a point is inserted in all routes along that segment, such that they share it.

Parameters

Name Type Description Default
routes dict[int, list[Coord]] per key, the coordinates of a route from start required
start Coord the start of the routes, from which the first point is attached if there are no routes required
points dict[int, Coord] per key, a point to attach required

Returns

Name Type Description
dict[int, list[Coord]] the routes, with a route to each point

branch_from_route

flow_paths.branch_from_route(model, node_id, basin_id, towards_id, margin=1.0)

Let the link from basin_id into node_id branch off the route from basin_id towards towards_id.

The branch starts at a Junction at the point of that route nearest to node_id, or at the existing Junction if that point is within margin of one, and runs straight to node_id. Returns the node id of that Junction.

merge_inflows

flow_paths.merge_inflows(model, basin_id, node_ids)

Replace the flow links from basin_id to node_ids by a link to a new Junction, with straight links on.

The Junction is at the centroid of node_ids, see place_on_link to move it. Returns its node id.

merge_outflows

flow_paths.merge_outflows(model, node_ids)

Connect node_ids with straight links to the first Junction downstream that all of their routes pass.

The Junctions they passed before are pruned. Returns the node id of the Junction.

place_on_link

flow_paths.place_on_link(model, node_id, basin_id, link_id)

Move node_id onto the point of link_id nearest to it, with its link with basin_id along their route.

link_id is on the route of basin_id in either direction, see Routes.paths, and node_id has a single flow link with basin_id. Its other links move their ends along.

prune_junction

flow_paths.prune_junction(model, junction_id)

Remove a Junction without inflow or outflow, or merge the two links of a Junction that only passes flow on.

Neighboring Junctions are pruned in turn. A Junction with other links, such as observation links, is kept.

rebuild_junction_trees

flow_paths.rebuild_junction_trees(model, basin_ids, waterways, tolerance=10.0)

Route the flow links of Basins along the waterways, with their Junctions where the routes split.

The Junctions of a Basin are removed if they only pass the flow out of, or into, that Basin, see junction_tree, except observed Junctions and RWZI Junctions. The links to the nodes they reach are routed from the Basin node along the shortest paths of one network, see ribasim_nl.network_snapping.route_basin_links, such that the routes out of and into a Basin share their common parts, and new Junctions are added where they split. Nodes far from the waterways branch off straight from the nearest point of these routes, see attach_to_tree, also over open water, where routes over the water surface would run in parallel. Each node keeps exchanging water with the same nodes, which is asserted, and the links to the nodes reached keep their link ids. Nodes are not moved and links are not offset, see ribasim_nl.layout.tidy_layout.

Parameters

Name Type Description Default
model Model Ribasim model required
basin_ids typing.Iterable[int] Basins to rebuild the Junctions of required
waterways gpd.GeoDataFrame waterways with a boolean “main-route” column, see ribasim_nl.network_snapping.snap_to_network required
tolerance float buffer around the basin area within which waterways are used, defaults to 10.0 10.0

Returns

Name Type Description
tuple[list[int], list[int]] the ids of the links and of the Junctions that are new or changed

rebuild_junction_trees_along_top10nl

flow_paths.rebuild_junction_trees_along_top10nl(
    model,
    basin_ids,
    top10nl_path,
    main_route,
    tolerance=250.0,
)

Rebuild the Junctions of Basins along the Top10NL water lines and a main route, see rebuild_junction_trees.

This is used for the hws model and again after coupling, such that its Basins keep their routes. Its connector nodes are often outside the area of their Basin, so waterways up to tolerance around it are used.

tree_links

flow_paths.tree_links(routes)

The links of the tree of routes that all start at the same point, with a Junction where they split.

The last segment of each route is its own, so a route that is part of another one still ends in a branch.
