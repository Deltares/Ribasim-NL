webmap_diff

webmap_diff

Compare two Ribasim models for the model viewer, to review the changes of a pull request.

Nodes are matched by node_id, and links by from_node_id and to_node_id, since links get renumbered. A feature in both models is changed if its geometry, an attribute, its rows in an input table or its Basin / area differ. Initial Basin levels within 1 cm are equal, see TABLE_TOLERANCES. If both models have results, the Basin levels and flow rates that differ are listed too.

compare_features

webmap_diff.compare_features(base, head, id_column, key=None)

Compare features matched on the key columns, by default the id column.

Return the added and changed features by head id, and the removed features by base id. Changed features list the columns that differ, and have their base_id if it differs from their head id.

compare_results

webmap_diff.compare_results(base, head, base_ids, atol, rtol)

Compare a result variable at the time steps of both models, for the features matched by base_ids.

Returns the number of compared features, and the difference head - base with the largest magnitude per head id, for features where it exceeds atol plus rtol times the largest magnitude of the feature. A value missing in one model only is a difference of unknown size, reported as None.

diff_models

webmap_diff.diff_models(
    base_toml,
    head_toml,
    base_dir,
    head_dir,
    output_path,
    labels=None,
)

Compare two models and their export_webmap output, and write the differences as JSON.

Nodes and links map ids to {"status": "added" | "removed" | "changed", "changes": [...]}, where the changes name the attribute columns, the tables, “geometry” or “Basin / area” that differ. Changed links have a base_id if they were renumbered. Removed links are keyed by their negated base link_id, since that id may be used by another link in the head model. If both models have results, results has the Basin levels and flow rates that differ per head id, see compare_results, otherwise it is None. Results whose links are not those of their model are outdated, and are not compared; results_note then says why. The labels name the models, by default their model names.

webmap_diff.nodes_differ_within(base_path, head_path, tolerances)

The node_ids whose rows in a table differ, with the columns of tolerances equal within their tolerance.

Rows are matched by node_id and their order per node. The whole table is read, so this is only for small tables.
